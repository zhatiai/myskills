# MySkills

用于集中编写和维护个人 Skills，也用于整理值得收藏的远端精选 Skills。项目按用途做简单分类，每个条目使用独立目录，并在自己的目录中提供 `SKILL.md`；远端精选条目只保留能力摘要与项目来源，不镜像实现内容。

## 目录

- [`technical/`](technical/)：开发、架构、测试、平台等技术类 Skills。
- [`tools/`](tools/)：效率工具、自动化、内容处理等工具类 Skills。

## Skills 索引

- [`technical-notes-5w1h`](technical/technical-notes-5w1h/)（自维护）：将技术概念、机制、架构、协议或源码原理整理为高信息密度的中文 Markdown 笔记。用于提炼技术知识、形成可复习笔记或明确要求 5W1H 时；不用于即时故障排查、代码修改或普通摘要。
