# MySkills

用于集中整理和维护个人 Skills。项目按用途做简单分类，每个 Skill 使用独立目录，并在自己的目录中提供 `SKILL.md`。

## 目录

- [`technical/`](technical/)：开发、架构、测试、平台等技术类 Skills。
- [`tools/`](tools/)：效率工具、自动化、内容处理等工具类 Skills。

## Skills 索引

- [`technical-notes-5w1h`](technical/technical-notes-5w1h/)：将技术概念、机制、架构、协议或源码原理整理为高信息密度的中文 Markdown 笔记。用于提炼技术知识、形成可复习笔记或明确要求 5W1H 时；不用于即时故障排查、代码修改或普通摘要。
- [`agents-md-author`](tools/agents-md-author/)：创建、审查或精简 Codex 的 AGENTS.md 与 AGENTS.override.md，并按目录作用域组织持久项目指令。用于用户要求新增、修改、拆分或审计代理说明文件时；不用于编写 SKILL.md 或一次性任务提示词。
